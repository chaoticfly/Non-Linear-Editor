# User Guide

Welcome to Likhi Lakeerain, a unique non-linear editor that helps you organize thoughts, ideas, and content using a grid-based timeline system.

## Getting Started

### Creating Your First Project

1. When you first open the application, you'll see a grid with horizontal and vertical lines
2. The default grid has 3 horizontal and 5 vertical lines
3. You can customize this in the settings (accessible through the header menu)

### Adding Content

#### Placing Markers

1. **Click on any line** to place a marker at that position
2. A new marker will appear with an editor popup
3. Add a title and content to your marker
4. You can customize the marker's color, category, and tags

#### Editing Markers

1. **Click on any existing marker** to open the editor
2. Modify the title, content, or metadata
3. Changes are saved automatically when you close the editor

### Organizing Your Content

#### Using Tags and Categories

1. Add tags to group related markers
2. Assign categories for broader organization
3. Use the sidebar to filter by tags or categories

#### Customizing the Grid

1. Open the settings menu from the header
2. Adjust the number of horizontal and vertical lines
3. Toggle visibility of horizontal or vertical lines
4. Customize the snap threshold for marker placement
5. Change the background color

### Compile Mode

The compile feature allows you to arrange markers in a specific order for final output:

1. Click the "Compile" button in the header
2. The compile drawer will open on the right side
3. Add markers to the compile list by clicking the "Add to Compile" button in the marker editor
4. Reorder markers in the compile list using drag and drop
5. The compiled content will be organized in the order shown in the compile drawer

## Interface Overview

### Header

- **Project Name**: Click to rename your project
- **Settings**: Access grid configuration and preferences
- **Compile**: Toggle the compile drawer
- **Sidebar**: Toggle the organization sidebar
- **Save/Load**: Project persistence options

### Main Canvas

- The central area where your grid and markers are displayed
- Click on lines to add markers
- Click on markers to edit them
- Hover over elements for visual feedback

### Sidebar

- **Filters**: Filter markers by tags or categories
- **Marker List**: View all markers in your project
- **Search**: Find specific markers by content

### Compile Drawer

- **Compile List**: Ordered collection of markers for output
- **Reordering**: Drag and drop to change the order
- **Clear**: Remove all markers from the compile list

## Working with Markers

### Marker Properties

Each marker has several properties you can customize:

- **Title**: A short label for the marker
- **Content**: Rich text content (supports formatting, lists, links)
- **Color**: Visual indicator (red, orange, yellow, green, teal, blue, violet, pink, gray)
- **Category**: Broad grouping classification
- **Tags**: Specific labels for detailed organization

### Marker Interactions

- **Click**: Open the editor to modify the marker
- **Hover**: See a tooltip with marker information
- **Add to Compile**: Include in the compilation list

## Customization

### Grid Settings

Access the grid settings through the header menu:

- **Horizontal Lines**: Number of horizontal timelines (0-10)
- **Vertical Lines**: Number of vertical timelines (0-10)
- **Show Horizontal**: Toggle visibility of horizontal lines
- **Show Vertical**: Toggle visibility of vertical lines
- **Snap Threshold**: Sensitivity for clicking near lines (pixels)
- **Background Color**: Canvas background color

### Visual Preferences

- Choose from multiple background color options
- Dark themes for reduced eye strain
- Light themes for better readability

## Tips and Tricks

### Efficient Workflow

1. **Use Categories** for high-level organization (e.g., "Research", "Ideas", "Tasks")
2. **Apply Tags** for detailed grouping (e.g., "Urgent", "Client A", "Feature")
3. **Customize Colors** to visually distinguish different types of content
4. **Use Compile Mode** to arrange content in a logical sequence for presentation

### Keyboard Shortcuts

- **ESC**: Close the marker editor
- **Enter**: Save and close the marker editor
- **Ctrl+S**: Save project (when implemented)

### Best Practices

1. **Keep Titles Concise**: Use clear, descriptive titles for quick scanning
2. **Organize Early**: Apply categories and tags as you create markers
3. **Use Compile Mode**: For creating structured documents from your non-linear content
4. **Regular Saving**: Save your projects frequently (when persistence is implemented)

## Troubleshooting

### Common Issues

#### Markers Not Placing Correctly
- Adjust the snap threshold in settings
- Ensure you're clicking close enough to a line

#### Performance Issues
- Reduce the number of lines in dense grids
- Limit the number of markers in a single project
- Close the compile drawer when not in use

#### Editor Not Opening
- Ensure you're clicking directly on a marker
- Refresh the page if the editor becomes unresponsive
